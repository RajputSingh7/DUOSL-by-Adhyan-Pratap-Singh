DUOSL (Dual OUTPUT Sign language Translator)

link for daily log file:
DUOSL is an end-to-end sign language translation system designed to bridge communication gaps between sign language users and non-signers.
It supports two integrated pipelines:

Sign Language → Text (via webcam, MediaPipe, and ML)

Text → Sign Language (via Unity-based 3D avatar animation)

The system focuses on real-time performance, stability, and accessibility, making it suitable for assistive communication and interactive applications.
